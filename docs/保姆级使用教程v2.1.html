0这是什么

Wlan-Flash-Transfer-V2 是一个局域网文件互传工具:电脑上启动服务, 同一 Wi-Fi 下的手机/平板/另一台电脑扫码或输入地址打开网页, 就能互相传文件、实时聊天 —— 不用数据线、不用登录、文件不限大小。

核心能力说明
📱 屏上二维码启动服务后电脑屏幕直接显示二维码,手机抬手就扫
🔐 4 位配对码可开启配对校验:网页需输入屏幕上显示的 4 位数字码才能使用
📖 只读模式切换为「仅下载」,适合纯分享场景,防误删
📂 文件管理桌面端表格化管理:预览 / 复制 / 删除 / 双击打开
💬 聊天镜像网页端聊天消息实时同步到电脑「聊天」页
📋 托盘常驻关窗最小化到菜单栏,服务不中断;菜单栏一键退出
💡 支持平台:macOS(.app)与 Windows(单文件 .exe)。产物自带运行时, 目标电脑无需安装 Python,双击即用。

160 秒极速上手

1

双击打开 Wlan-Flash-Transfer-V2.app(Windows 为 .exe),点蓝色「启动服务」→ 徽标变绿「● 运行中」,右侧出现二维码。

2

手机连同一个 Wi-Fi,相机扫屏幕右侧的二维码 → 打开网页。

3

网页里把文件拖进虚线框(手机点虚线框选相册照片)→ 进度条跑完,文件已躺在电脑共享目录里。

✅ 就这三步。默认无需输入配对码(校验开关默认关闭);开启方法见第 5 章。

2开始前 2 分钟准备

  • 同一 Wi-Fi:手机和电脑连名字完全相同的网络;路由器开了「AP 隔离/访客网络」会互相看不见,需关闭或换网。
  • 防火墙放行:macOS 首次启动若弹「是否允许接受传入网络连接」点「允许」;Windows 同理。
  • 打包版用户:无需安装任何东西。源码用户需 Python 3.8+ 与 PyQt6:
    pip3 install -r requirements.txt python3 main.py

3认识主界面(已停止状态)

1状态徽标:○ 已停止(灰)→ ● 启动中(黄)→ ● 运行中(绿)
2访问地址:启动后显示,蓝色等宽字体,可选中复制
3端口:默认 8765,可改(1-65535);运行中锁定
4共享目录:文件存放位置,默认 ~/Wlan-Flash-Transfer;「浏览…」可换
5访问令牌 + 配对校验开关:4 位数字配对码;开关默认关闭,详见第 5 章
6权限模式:完整(上传/下载/聊天)/ 仅下载(只读),切换按钮即时生效
7可用空间:共享目录所在磁盘剩余容量
8启动 / 停止服务:蓝色主按钮;运行中切换为「停止服务」可点
9共享文件表:文件名 / 操作(预览·复制)/ 大小 / 修改时间;删除选中 + 刷新
10手机扫码直达:启动后此处显示大二维码
11服务日志:右侧二维码下方,每条请求带时间戳
12状态栏:最新状态消息;后台任务时右侧显示 ⏳

4启动服务:运行中 + 屏上二维码

1

确认端口与共享目录(一般不用动),点「启动服务」。约半秒后徽标变绿,地址栏显示访问地址,右侧出现二维码。

A二维码:内容为带配对参数的完整地址 —— 开启配对校验时,扫码即完成配对
B操作列:每个文件行有「预览」(直接打开)与「复制」(文件进剪贴板)两个按钮
C服务日志:服务启动、访问地址、每条 HTTP 请求都在这里,排障先看它
4

失败处理:端口被占 → 弹窗提示,换端口重试;目录不可写 → 换目录。两种失败都会自动还原按钮,不会卡死。

💡 关窗 ≠ 退出:点窗口 ✗ 会最小化到菜单栏(Tray),服务继续运行 —— 手机随时扫码都能传。彻底退出:点菜单栏图标 → 菜单「退出」。Mac 点 Dock 图标可唤回窗口。

5配对校验:4 位码保护(默认关闭)

想让局域网里只有知道配对码的人能用?开启配对校验:

1

勾选「开启配对校验」—— 开关默认关闭,勾上即刻生效(服务运行中也能切换)。

2

把屏幕上显示的 4 位配对码(如 1969)告诉要传文件的人 —— 或者让他们扫二维码,码已包含在链接里,扫码免输码直接用。

3

手动输入地址(没扫码)的人,网页会弹出配对框,输入 4 位码即可:

需要配对

输入电脑「访问令牌」完成配对

▲ 网页端配对框示意(输入屏幕上的 4 位数字)

  • 配对码可在桌面端「重新生成」,旧码立即失效(相当于踢出所有已配对设备)
  • 关闭配对校验开关 → 恢复免输码,任何人扫码即用
  • 校验开启时:只读模式同样受保护,下载也需要配对码
⚠️ 忘了配对码?看电脑「服务配置」区的访问令牌行,或点「重新生成」换个新码。

6权限模式:完整 vs 仅下载

「权限模式」是两个互斥的切换按钮,服务运行中切换即时生效:

模式网页能做什么适用场景
完整(上传/下载/聊天) —— 默认上传、下载、删除、聊天全开家人朋友互传文件
仅下载(只读)只能浏览和下载,上传/聊天/删除全部隐藏并禁用,页面顶部显示 🔒 横幅发材料给一群人;防误删
💡 只读模式开启后,网页端的上传区和聊天输入框会自动消失并显示 「🔒 只读模式」横幅 —— 对方想传也传不了,防误操作。

7手机网页端:上传 / 下载 / 聊天

扫码(或输地址)打开网页后,整页分上下两屏:

功能用法
上传拖文件进虚线框(电脑)/ 点虚线框选择(手机传相册);支持批量
粘贴上传电脑截图后 Ctrl+V / ⌘V 直接贴进页面
实时进度每个文件独立进度条 + 速度,完成变绿
下载点文件名或「下载」;图片自动缩略图
删除 / 排序行内删除按钮(删的是电脑磁盘原文件);最新/名称/大小排序
二维码页面右上按钮再显示二维码,方便第二台设备接入
💡 网页上传没有大小限制,原图无损;速度取决于 Wi-Fi(5G 频段更快)。

8聊天镜像:电脑上实时看消息

网页端任何人发的消息,实时同步到桌面「聊天」Tab:

  • 格式:[时间] 昵称(IP): 消息,来源设备一目了然
  • 「清空显示」只清屏幕,不影响网页端
  • 回复在网页端发 —— 桌面端是围观镜

9文件管理:预览 / 复制 / 删除

操作怎么做
预览文件行「操作」列点「预览」,或双击行 —— 用系统默认程序直接打开
复制点「复制」—— 整个文件进剪贴板,去访达/资源管理器 ⌘V/Ctrl+V 粘贴出去
删除选中行 → 红色「删除选中」→ 确认框 → 从磁盘删除并自动刷新列表
刷新「↻ 刷新」按钮 / F5;刷新后列表自动回到顶部
换目录停止服务 →「浏览…」选新目录 → 再启动;「打开共享目录」直达该文件夹
⚠️ 网页端与桌面端的「删除」都从电脑磁盘真删(有确认框兜底),重要文件先备份。

11常见问题急救箱

手机扫二维码打不开页面
① 确认同一 Wi-Fi;② 地址带 http:// 和端口;③ 路由器「AP 隔离/访客网络」会隔离设备; ④ 电脑防火墙首次弹窗点「允许」。
开启配对校验后,网页一直弹「需要配对」
输的是屏幕上的 4 位数字(在桌面端「访问令牌」行,或重新生成一个)。 扫码打开的链接自带配对参数,无需手输;手输地址的才需要输入。
启动服务弹「端口被占用」
换个端口(如 9000)再启动。查占用:Mac lsof -i :8765, Windows netstat -ano | findstr 8765。
上传失败「磁盘空间不足」
共享目录所在磁盘剩余空间不足:清理磁盘或「浏览…」换目录(可用空间行会实时显示)。
macOS 提示「已损坏,无法打开」
xattr -dr com.apple.quarantine /path/to/Wlan-Flash-Transfer-V2.app 后重开; 或右键 →「打开」。
Windows 双击被 SmartScreen 拦截
未签名单文件 exe 的常见误报:「更多信息 → 仍要运行」。
传输速度慢
瓶颈在路由器/网卡:靠近路由器、连 5G Wi-Fi、电脑插网线都能提速。
停止服务后手机页面打不开了
正常 —— 服务已关。重新「启动服务」即可,地址不变时刷新页面就恢复。
换了共享目录后旧文件不见了
文件都在原目录里。切回原目录即可;删除操作只影响当前目录内的文件。

12安全须知

  • 默认无鉴权:同网段设备可浏览、上传、删除共享目录内容 —— 面向家庭/测试等可信网络
  • 办公网/半公开网络使用:建议开启配对校验 + 只读模式(防误删)
  • 公共 Wi-Fi 不要用;共享目录别指向含敏感文件的路径
  • 用完「停止服务」或关窗(收进菜单栏后记得从托盘退出)
