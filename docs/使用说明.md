# Wlan-Flash-Transfer-V2 · 使用说明

**局域网文件互传**:电脑上启动服务,同一 Wi-Fi 下的**任何设备**(手机/平板/电脑,
iOS/Android/macOS/Windows/Linux)用浏览器打开地址,即可互相传文件、分享、聊天。
无需数据线、无需登录、无需装客户端。

> v2 = PyQt6 重写版(深色界面 + 屏上扫码 + 布局E 网页端);v1(tkinter 版)仍可用,两者互不影响。

---

## 一、30 秒上手

1. 双击打开 `Wlan-Flash-Transfer-V2.app`(Windows 为 `Wlan-Flash-Transfer-V2.exe`)
2. 点蓝色「**启动服务**」→ 状态变绿「● 运行中」
3. 手机相机**扫右侧二维码**(或浏览器输入显示的地址,如 `http://192.168.1.179:8765`)
4. 网页里把文件**拖进去** —— 完成,电脑「共享文件」表格里立刻能看到

前提只有一个:**手机和电脑连同一个 Wi-Fi**。

---

## 二、桌面端(电脑)功能

| 控件 | 说明 |
|---|---|
| 状态徽标 | ○ 已停止 / ● 启动中 / ● 运行中 |
| 地址 + 复制链接 | 启动后显示访问地址,一键复制 |
| 打开浏览器 | 在电脑上打开网页版(自测用) |
| 端口 | 默认 `8765`,可改(1-65535);运行中锁定,停止后可改 |
| 共享目录 | 传的文件存这里;点「浏览…」换任意文件夹;运行中锁定 |
| 可用空间 | 实时显示目标磁盘剩余/总容量 |
| 启动 / 停止服务 | 蓝色主按钮启动;停止后端口立即释放 |
| 打开共享目录 | 在访达/资源管理器里打开当前共享目录 |
| 共享文件表 | 名称/大小/修改时间;行内「预览 / 复制」按钮;**双击行**用系统默认程序打开;选中后「删除选中」(有确认框);↻ 刷新 |
| 手机扫码直达 | 右侧二维码,启动后显示,手机扫码直达网页 |
| 聊天 Tab | 网页端聊天的实时镜像(桌面端只能看,回复在网页上发) |
| 服务日志(右侧二维码下方) | 每条 HTTP 请求与服务事件,带时间戳 |
| 服务 Tab 之外 | 菜单「文件 → 刷新文件列表(F5)」「帮助 → 关于」 |

> **关窗 ≠ 退出**:点窗口 ✗ 会最小化到系统托盘,服务保持运行
> (手机随时可传);从托盘图标菜单选「退出」才真正退出。首次收起会有气泡提醒。

## 三、浏览器端(手机/平板/其他电脑)功能

网页端为「布局E」界面,按屏幕宽度**自动切换**布局,无需设置:
桌面(>980px)为左右等宽分栏(文件 | 聊天);手机(≤980px)为单列 + 右下角 💬 悬浮球聊天。

| 功能 | 用法 |
|---|---|
| 上传 | **拖拽**进虚线框 / 点击选择(**支持批量**)/ `Ctrl+V` / `⌘V` 直接**粘贴**(截图神器) |
| 实时进度 | 每个文件独立进度条 + 实时速度,完成变绿自动收起 |
| 下载 | 点文件名或蓝色下载按钮;图片有缩略图预览 |
| 删除 | 灰色删除按钮,有确认框;当前页删空自动回退上一页 |
| 分享 | 绿色分享按钮:手机调起**系统分享面板**;电脑**复制下载链接**(有提示) |
| 排序 / 分页 | 最新/名称/大小三档排序;每页 8 个文件,底部页码导航 |
| 聊天 | 右侧聊天卡(手机在悬浮球里):昵称按设备自动生成并记住,头像由昵称映射 emoji;局域网内所有设备实时互通 |
| 二维码 | 页面右上按钮可再显示二维码,方便第二台设备接入 |

传完的文件都在电脑的**共享目录**里(默认 `~/Wlan-Flash-Transfer`),桌面端可双击直接打开。

> 聊天昵称:首次访问按设备自动生成(如 `iPhone-8231`、`Mac Chrome-3387`)并固定;
> 可自定义,自动记住。头像由昵称自动映射 emoji,同一昵称在所有设备上头像一致。

## 四、典型场景

**手机 → 电脑**:手机拍照后网页上传,电脑共享目录直接取。
**电脑 → 手机**:电脑把文件放进共享目录(或拖拽上传),手机网页点下载。
**电脑 → 电脑**:另一台电脑开浏览器访问即可,不挑系统。
**发文件给同事**:网页里点绿色分享按钮——手机直接调起微信/QQ 分享,电脑复制下载链接发过去。
**发 exe 给同事**:Windows 版是单文件 exe,直接发过去,对方双击就能当服务端。

## 五、打包分发

```bash
# macOS(在 Mac 上)→ dist/Wlan-Flash-Transfer-V2.app
bash build.sh

# Windows(在 Windows 上)→ dist\Wlan-Flash-Transfer-V2.exe(单文件)
build_windows.bat        # PowerShell 里要写 .\build_windows.bat
```

两个脚本都会在打包后**自动跑冒烟自检**(起服务→请求接口→停止),
看到 `[OK]` / `SMOKE_OK` 才算成功。产物自带运行时,目标机器无需装 Python。

打包配置已做产物瘦身(剔除未使用的 Qt 组件/插件/翻译 + macOS strip):
mac .app 74MB → **56MB**;修改 `lan-transfer-v2.spec` 过滤清单后,
务必 `--smoke` + `--screenshot` 双验证。

命令行自检:

```bash
python3 main.py --smoke        # 无头自检
python3 main.py --screenshot s.png   # 无头截图
```

## 六、常见问题

| 现象 | 处理 |
|---|---|
| 手机打不开地址 | ① 确认同一 Wi-Fi ② 部分路由器开了「AP 隔离/访客网络」,关掉或换网络 ③ 地址输完整(带 `http://` 和端口) |
| 部分浏览器打开页面无数据、聊天发不出 | 浏览器内核过旧(<2017)。已兼容 Chrome 55+/Safari 10.1+;请升级浏览器或换现代浏览器 |
| 点复制按钮没反应 | 新版已兼容局域网 HTTP 环境;若仍失败会提示手动复制并自动选中地址,`Ctrl+C` 即可 |
| 启动失败(端口被占用) | 换个端口再启动;或 `lsof -i :8765`(Win:`netstat -ano | findstr 8765`)找到占用进程 |
| 上传失败「磁盘空间不足」 | 共享目录所在磁盘满了,清理或换目录 |
| 传输速度慢 | 瓶颈是路由器/网卡;5G Wi-Fi 或有线可跑满,2.4G 慢属正常 |
| macOS 提示「已损坏,无法打开」 | `xattr -dr com.apple.quarantine dist/Wlan-Flash-Transfer-V2.app` 后重开 |
| Windows 打开被 SmartScreen 拦 | 未签名 exe 的常见误报,点「更多信息 → 仍要运行」 |
| 中文文件名下载乱码 | 不会 —— 服务端已按 RFC 5987(`filename*=UTF-8''`)下发;若遇到请反馈 |
| 网页聊天的消息电脑上看得到吗 | 看:桌面「聊天」Tab 实时镜像;但回复要在网页端发 |
| 手机上找不到聊天入口 | 右下角 💬 悬浮球,点开即聊天面板;来新消息有红色数字角标 |
| 停止服务后手机还开着页面 | 页面刷新会失败,属正常;重新启动服务即可 |
| 换了共享目录后旧文件不见了 | 文件都在原目录里,切回原目录即可;删除只删当前目录内文件 |

## 七、安全须知

- 本工具面向**可信局域网**(家庭/测试环境),**无鉴权**:同网段任何设备
  都能浏览、上传、删除共享目录里的文件
- 请勿在公共 Wi-Fi(咖啡馆/机场)使用;勿把共享目录指向含敏感文件的路径
- 用完建议点「停止服务」
