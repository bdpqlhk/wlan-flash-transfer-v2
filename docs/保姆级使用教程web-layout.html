0这是什么

Wlan-Flash-Transfer-V2 是一个局域网文件互传工具:电脑上启动服务, 同一 Wi-Fi 下的手机/平板/另一台电脑扫码或输入地址打开网页, 就能互相传文件、实时聊天 —— 不用数据线、不用登录、文件不限大小。

┌─────────── 电脑(桌面应用) ───────────┐ │ 启动服务 · 二维码 · 配对码 · 文件表 │ └───────────────┬──────────────┘ │ 局域网 (同一 Wi-Fi) ┌───────────────┼──────────────┐ 📱 手机 📱 平板 💻 另一台电脑 浏览器打开网页: 上传 / 下载 / 分享 / 聊天
核心能力说明
🖥 桌面应用启动/停止服务、选共享目录、看日志、扫码、聊天镜像
🌐 网页端(布局E)桌面等宽分栏、手机悬浮聊天;上传点击/拖拽/粘贴,文件分页管理
🔐 4 位配对码开启后网页需输入配对码才能使用,防陌生人
📖 只读模式一键切换「仅下载」,适合纯分享场景,防误删
💬 实时聊天三端实时互通;昵称自动生成,emoji 头像
本教程对应 v2.1.x 代码线,全部截图均来自当前最新代码的实际运行画面。

160 秒极速上手

1

电脑上启动

打开应用 → 点 「启动服务」 → 状态变绿色 ● 运行中,窗口出现二维码(见第 4 节)。

2

手机扫码

相机对准二维码 → 网页自动打开(若开启配对,输入窗口上的 4 位码,见第 12 节)。

3

传文件

拖拽/点选/粘贴上传 → 进度条跑完即到电脑(见第 7 节)。

4

取文件

电脑点「打开共享目录」;或手机在网页里点蓝色下载按钮。

完成!建议正式使用前按第 12/13 节开启配对或只读模式。

2运行方式:开发 / 打包

方式 A:直接运行(有 Python 环境)

pip3 install -r requirements.txt # PyQt6 (+ PyInstaller 可选) python3 main.py # 启动图形界面

方式 B:打包成免安装应用(推荐分发)

bash build.sh # macOS → dist/Wlan-Flash-Transfer-V2.app build_windows.bat # Windows → dist\Wlan-Flash-Transfer-V2.exe(单文件)
  • 打包产物自带运行时,对方无需安装 Python
  • macOS 被 Gatekeeper 拦截时:xattr -dr com.apple.quarantine dist/Wlan-Flash-Transfer-V2.app
打包产物已做瘦身优化(剔除未使用的 Qt 组件与翻译),macOS 版约 56MB。

4启动服务:运行中 + 二维码

1

选共享目录(可选)

默认共享 ~/Wlan-Flash-Transfer,点「浏览…」可换;目录里的已有文件直接出现在列表。

2

点「启动服务」

徽标变 ● 运行中,地址与二维码出现,「停止服务」同时激活。

3

用完点「停止服务」

端口释放,网页立即无法访问;文件仍在共享目录里。

端口被占用时启动会失败,日志给出原因——换一个端口(如 8766)再启动即可。

5进入网页端:三种方式

1

扫码(手机推荐)

相机对准应用窗口的二维码——直达页面,免输地址。

2

输地址

浏览器输入应用显示的地址,如 http://10.161.123.131:8765。

3

点「打开浏览器」(本机)

在电脑本机直接打开网页端。

手机必须与电脑在同一局域网;公司网络若开了 AP 隔离,可用手机热点验证。

7上传文件:点选 / 拖拽 / 粘贴

⬆️
点击选择文件 或 拖拽到此处

支持多选 · 可直接 Ctrl+V / Cmd+V 粘贴文件
无大小与类型限制 · 局域网内满速传输

三种方式任选,都支持一次多个文件:

方式操作适合场景
点击选择点上传区 → 文件选择框 → 按住 Ctrl/Cmd 多选文件在深层文件夹
拖拽把文件拖到上传区,边框变蓝时松手手里正开着文件夹
粘贴复制文件后在页面按 Ctrl+V / Cmd+V截图直接粘贴
  • 每个文件独立进度条,实时显示百分比 + 速度;完成变绿自动收起
  • 传完立即出现在「共享文件」列表第 1 页
  • 上传前服务端自动检查磁盘剩余空间,不足明确报错

8下载 / 删除 / 分享:三色按钮

每个文件行末尾固定三个等大按钮,颜色即含义(见第 6 节大图文件行右侧):

⬇下载(蓝) 🗑删除(灰) ⤴分享(绿)
按钮功能说明
蓝 = 下载把文件下载到本机点文件名同样可下载;图片直接显示缩略图与「预览」标记
灰 = 删除从共享目录删除确认弹窗,不可撤销;当前页删空自动退回上一页
绿 = 分享分享这个文件手机:系统分享面板;电脑:复制下载链接(自带令牌)+ 绿色提示
桌面应用的共享文件表里也能「删除选中」批量管理,行内「预览/复制」直接打开或复制文件。

10聊天室:昵称 / 头像 / 桌面镜像

  • 昵称:首次按设备自动生成(如 iPhone-8231、Mac Chrome-3387)并永久固定;可自定义并自动记住;留空则用自动昵称

12配对码:4 位数字保护

担心同网内陌生人访问?在桌面端勾选「开启配对校验」:

此时任何人打开网页,会先看到配对弹层:

  • 配对一次长期有效(存在本机浏览器);换设备需再输一次
  • 点「重新生成」旧码立即失效,已配对的设备也会被要求重新输入
  • 分享按钮复制出的链接自带令牌,同事点开无需再配对
  • 取消勾选即关闭配对,恢复完全开放

13只读模式:仅下载

纯分享场景怕误删/误传?权限模式点一下 「仅下载(只读)」:

  • 只读对所有网页访客生效(含已配对设备)
  • 桌面端文件表不受影响,仍可正常管理
  • 切回「完整(上传/下载/聊天)」即恢复全部功能

14复制链接与二维码

  • 网页端复制按钮:一键复制服务地址(开启配对时自动带令牌);局域网 HTTP 环境自动降级兼容,失败时自动选中地址方便手动复制
  • 桌面端「复制链接」:同样一键复制
  • 二维码:桌面屏上直接显示、网页端弹窗大图,全部本地生成不依赖外网

15服务日志 / 托盘 / 退出

  • 服务日志:右下角日志区逐行记录(服务启动、访问地址、每个 HTTP 请求),见第 4 节运行图右下
  • 系统托盘:关闭窗口 = 收到托盘,服务继续跑;托盘图标可快速重开窗口
  • 彻底退出:菜单栏「文件 → 退出」(或托盘菜单),服务随之停止
异常闪退时日志写入 ~/Library/Logs/LAN文件传输v2.log(macOS),反馈问题附上它最有用。

16常见问题急救箱

手机打不开网页 / 一直转圈?
① 确认同一 Wi-Fi;② 确认服务 ● 运行中;③ 公司网络可能有 AP 隔离,换手机热点试;④ 核对 IP 端口与桌面端一致。
网页一直弹「需要配对」?
输入桌面端「访问令牌」框里的 4 位数字;输错会再次弹出。若桌面端重启过服务,配对码可能已变,以桌面端实时显示为准。
点「启动服务」失败?
看服务日志:多为端口被占用——换个端口再启动;或共享目录被删除/无权限——重新选择目录。
上传到一半失败?
进度条变红有原因提示:磁盘空间不足会写明需要/可用多少;网络闪断重新上传即可。只读模式下上传入口会隐藏,属正常。
手机上找不到聊天室?
右下角 💬 悬浮球里,见第 11 节。只读模式下聊天输入框隐藏,仅可查看。
网页复制的链接粘贴不了?
新版已做降级兼容;若仍失败会提示手动复制且地址自动选中,Ctrl+C 即可。
删错文件了怎么办?
删除立即生效且无回收站——只能重新上传。重要文件建议先下载备份再删。
