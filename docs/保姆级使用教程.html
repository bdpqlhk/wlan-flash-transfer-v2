0v2 是什么,和 v1 什么关系

v2 是 v1 的 PyQt6 重写版:换上了深色开发者工具风格界面,服务器代码重构成 可独立测试的分层架构,并新增了三样 v1 没有的能力:

  • 屏上二维码:启动服务后电脑屏幕直接显示二维码,手机抬手就扫(v1 需要先开网页再点二维码按钮)
  • 聊天镜像:网页端的聊天消息实时显示在电脑「聊天」页,电脑上也能围观
  • 文件管理表格:电脑端直接查看共享目录里的文件,双击打开、勾选删除,不用去翻文件夹
💡 网页端(手机看到的页面)与 v1 完全一致 —— 已经会用的零学习成本。 v1(tkinter)和 v2 可以共存,数据互不影响,喜欢哪个用哪个。
你手上有怎么打开
打包好的 macOS LAN文件传输v2.app双击,什么都不用装
打包好的 Windows LAN文件传输v2.exe双击(单文件,可直接发给同事)
源码pip3 install -r requirements.txt → python3 main.py

160 秒极速上手

1

打开软件,点蓝色「启动服务」,徽标变绿色「● 运行中」。

2

手机扫屏幕右侧的二维码(或浏览器输入上方蓝色地址),打开网页。

3

把文件拖进虚线框 —— 完成,文件已躺在电脑的共享目录里。

✅ 就这么简单。前提只有一个:手机和电脑连同一个 Wi-Fi。往下看详细说明。

2开始前 2 分钟准备

  • 同一 Wi-Fi:手机和电脑连的名字完全相同的网络。公司/宿舍网开了「AP 隔离」或连了「访客网络」时设备互相看不见,需要换网或找管理员。
  • 打包版用户(.app / .exe):无需任何安装,直接跳到 第 3 章。
  • 源码用户:需要 Python 3.8+ 和 PyQt6:
    cd /path/to/lan-file-transfer-v2 pip3 install -r requirements.txt # PyQt6 + PyInstaller python3 main.py # 启动
  • 防火墙放行:macOS 首次启动服务若弹「是否允许接受传入网络连接」,点「允许」;Windows 同理。

3认识桌面端界面(已停止状态)

刚打开软件时长这样(真实界面截图),编号对应下表:

1状态徽标:○ 已停止(灰)→ ● 启动中(黄)→ ● 运行中(绿),全程一目了然
2访问地址:启动后显示,蓝色等宽字体,可选中复制
3端口:默认 8765,可改(1-65535);运行中锁定防误改
4共享目录:传的文件存放位置,默认 ~/LAN文件传输;「浏览…」可换任意文件夹
5可用空间:目标磁盘剩余容量,传大文件前先看一眼
6启动 / 停止服务:蓝色主按钮启动;运行中变「停止服务」可点
7共享文件表:目录里已有的文件(名称/大小/修改时间),双击行直接打开,选中后可删除
8二维码区:启动后此处显示大二维码,手机对准扫即可
9服务日志:底部 Dock,每条请求带时间戳;可从「视图」菜单开合
10状态栏:最新一条状态消息;有后台任务时右侧出现 ⏳
💡 复制链接 / 打开浏览器两个按钮在状态行右侧:一个复制地址发给同事, 一个在电脑上直接打开网页版预览。

4启动服务:绿色运行中 + 屏上二维码

1

确认端口和共享目录(一般不用动),点「启动服务」。

2

约半秒后徽标变绿「● 运行中」,地址栏显示完整地址,右侧出现二维码,底部日志记录启动事件:

3

启动失败的两种情况:① 端口被占用 → 弹窗提示,换个端口重试;② 共享目录不可写 → 换目录。都会自动还原按钮,不会卡死。

4

用完点「停止服务」,徽标回灰色,二维码消失,端口立即释放。

💡 需要长时间挂着服务?直接最小化窗口即可,服务照常运行;关窗会自动停止服务并退出。

5手机端:扫码上传 / 下载 / 聊天

1

手机连同一个 Wi-Fi,打开相机对准电脑屏幕上的二维码 → 顶部弹「打开网页?」→ 点击直达。

2

看到网页后,把文件拖进虚线框(电脑)或点虚线框选文件(手机传相册照片用这个)。

网页长下面这样(v2 网页与 v1 相同,用过 v1 的直接上手):

功能用法
上传拖拽 / 点选 / 截图后 Ctrl+V 粘贴,三种姿势,支持批量,逐文件进度条 + 实时速度
下载点文件名或蓝色「下载」;图片有缩略图;中文文件名不会乱码
删除🗑 会删除电脑磁盘上的原文件,误删找不回
排序最新 / 名称 / 大小 一键切换

💡 手机上传相册照片:iPhone 点虚线框 →「照片图库」多选;Android 在文件选择器里进 DCIM/Camera。批量几十张一次传完,原图不压缩。

6聊天镜像:电脑上实时看消息

网页端任何人发的消息,都会同步出现在桌面端「聊天」Tab —— 同事传完文件在网页里喊一句「收到了」,你盯屏幕就知道,不用来回切窗口:

  • 消息按 [时间] 昵称(IP): 内容 排列,来源设备一目了然
  • 「清空显示」只清屏幕,不影响网页端继续聊
  • 回复在网页端发 —— 电脑端是围观镜,不是输入端

7文件管理:打开 / 删除 / 换目录

操作怎么做
查看「服务」页的表格实时列出共享目录内所有文件(名称/大小/修改时间),上方显示总数
打开双击表格里的行,用系统默认程序打开该文件(图片看图、视频播放)
删除单击选中一行 → 点红色「删除选中」→ 确认框 → 从磁盘删除并自动刷新列表
刷新「↻ 刷新」按钮或菜单「文件 → 刷新文件列表(F5)」
换目录停止服务后,「共享目录」旁「浏览…」重选;「打开共享目录」按钮直达该文件夹
⚠️ 删除 = 从硬盘真删(有确认框兜底)。重要文件建议先归档再清理。

8实战案例

案例①:手机照片批量传电脑(原图无损)

1

电脑启动服务,手机扫码。

2

手机点虚线框 → 相册勾选几十张 → 上传,看进度条。

3

电脑点「打开共享目录」,照片已在 ~/LAN文件传输,原图无损,比微信传文件快且不压画质。

案例②:电脑大文件发手机

1

电脑把视频/安装包拖进网页端虚线框(或直接放进共享目录,点「↻ 刷新」)。

2

手机在文件列表点「下载」。iPhone 提示无法预览时点分享 →「存储到文件」。

✅ 案例③:给同事批量发材料 —— 你开服务,把链接发到群里,大家浏览器各取所需,不用微信挨个传。

9常见问题急救箱

手机扫二维码没反应 / 打不开页面
① 确认同一 Wi-Fi;② 手动输入地址时带上 http:// 和端口; ③ 路由器「AP 隔离 / 访客网络」会隔离设备,关闭或换网; ④ 电脑防火墙首次弹窗要点「允许」。
点启动服务弹「端口被占用」
8765 被占。把「端口」改成 9000、9999 等再点启动; 想查谁占用:Mac lsof -i :8765,Windows netstat -ano | findstr 8765。
二维码扫出来但页面很慢 / 空白
页面完全本地渲染,不存在网络加载问题;刷新一下即可。 仍白屏请确认地址没输错(端口要和「页面端口」一致)。
上传失败「磁盘空间不足」
共享目录所在磁盘剩余空间小于文件体积。清理磁盘,或「停止服务 → 浏览…」换到空间充足的盘,再启动。
可用空间显示「无法获取」
目录还没创建时软件会自动向上找已存在的上级目录估算;若仍提示, 先点一次「启动服务」(会自动建目录)再停掉,显示即恢复。
macOS 打开 app 提示「已损坏」/ Windows 提示 SmartScreen
Mac:xattr -dr com.apple.quarantine /path/to/LAN文件传输v2.app; Windows:SmartScreen 点「更多信息 → 仍要运行」。均为未签名程序的常规提示。
传输速度慢
瓶颈在路由器/网卡,与软件无关。设备离路由器近一点、连 5G Wi-Fi、 电脑插网线,都能显著提速。
停止服务后手机页面还能用吗
不能,刷新会失败(服务已关)。重新点「启动服务」即可,地址不变时手机刷新即可恢复。

10安全须知(30 秒读完)

  • 面向家庭 / 测试等可信网络:同网段任何人都能浏览、上传、删除共享目录文件,无鉴权。
  • 公共 Wi-Fi(咖啡馆/机场)不要用。
  • 共享目录默认 ~/LAN文件传输,别把它指向含敏感文件的路径。
  • 用完点「停止服务」或直接关窗。
